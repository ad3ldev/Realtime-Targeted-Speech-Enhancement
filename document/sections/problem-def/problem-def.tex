\section{Problem Definition}
Speech Enhancement is a signal processing task that involves improving the quality of speech signals captured under noisy or degraded conditions.

Speech enhancement aims to improve the clarity, understandability of speech signals.

We address the problem of speech enhancement in online communication.

The Speech Enhancement has been widely used for various applications such as:

\begin{itemize}
    \item Mobile Communication
    \item Teleconferencing
    \item Speech Recognition Systems
    \item Hearing Aids
\end{itemize}

For many such applications, a key feature of a speech enhancement system is to run in real time and with as little lag as possible (online), on the communication device, preferably on inexpensive hardware.

We will utilize Deep Learning methods for Real-Time Speech Enhancement, which are not performant as their non Real-Time counterparts.

We will try to enhance one of the current methods by utilizing a \textbf{clear speech} provided by \textbf{the device user}, to help the model in extracting and enhancing his voice in a noisy environment.
