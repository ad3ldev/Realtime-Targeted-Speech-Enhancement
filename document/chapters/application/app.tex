This section provides an overview of the application, detailing its primary components and functionality. The app is designed to facilitate user interaction through a graphical user interface (GUI), stream audio input for real-time processing, and apply our machine learning model to process the streamed audio. The workflow of the application is divided into two main stages before reaching the ML model: the GUI app and the streamer.

The first stage involves the GUI app, which serves as the interface for user interaction. Users input their data through this intuitive and user-friendly interface. The GUI is responsible for capturing user inputs and passing them to the subsequent stages of the application. It ensures that users can easily and effectively interact with the system, providing the necessary inputs required for further processing.

The second stage is the streamer, which handles real-time audio input. This component is used to capture the user's voice. The streamer is designed to efficiently manage and stream the audio data, ensuring that it is continuously fed into the system without interruptions. This real-time streaming capability is crucial for applications requiring immediate audio processing and analysis.
